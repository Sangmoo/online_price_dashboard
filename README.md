# ERP 영업 관리

영업 데이터 조회·관리용 로컬 웹 서비스입니다. 온라인몰 가격 수집 결과(`T_SELECT_ONLINE_MNG_R`) 분석과 매장 재고 실사계획(`T_SHOP_INVT_PLAN`) 관리를 제공합니다. React와 FastAPI로 만들었고, 대화형 분석에는 Claude API를 씁니다.

## 기능
| 화면 | 내용 |
|---|---|
| 로그인 | 사내 계정(`T_USR`)으로 로그인. 비밀번호는 DB 안에서 `CRYPTO_DECRYPT(PWD)`로 비교하고, `USE_YN='Y'`이면서 삭제되지 않은 계정만 허용. 5회 연속 실패하면 1분간 잠금 |
| 세션 | 1시간 동안 사용하지 않으면 자동 로그아웃. API 호출이나 화면 클릭·입력이 있으면 1시간으로 다시 연장. 만료 5분 전에 경고와 연장 버튼 표시 |
| 대시보드 | 최대 31일 기간 선택. KPI, 추이, 분포, 사이트·상품 순위 |
| 일자별 상세 | 컬럼 정렬, 통합 검색, 사이트·**할인율 범위** 필터, **표시 컬럼 선택**(사용자별 저장), **링크 복사**(현재 조건을 URL로 공유), 엑셀 다운로드 |
| AI 어시스턴트 | 우측 아래 💬 버튼. 이 서비스의 데이터(온라인 가격, 매장 재고 실사계획)만 조회해서 답변하고, 그 외 주제는 거절. **사용자의 메뉴 권한이 있는 데이터의 조회 도구만 제공**되며 서버에서도 한 번 더 권한을 검사. **대화 기록은 사용자별로 저장**되고 다시 열어 이어갈 수 있음. **즐겨찾는 질문** 저장, 결과 표를 **차트로 전환**하거나 엑셀로 저장. 오늘 사용량(질문 수·비용) 표시 |
| 데이터 관리 › 매장 재고 실사계획 | `T_SHOP_INVT_PLAN` 등록·수정·삭제(소프트 삭제). 매장코드 팝업에서 매장을 고르면 브랜드·유통·매장명·전년/당년 매출·최종실사일·관리등급(`T_SHOP_INVT_RANK`)·재고·매장번호가 자동으로 채워지고, 조회되지 않은 항목은 "데이터 없음"으로 표시해 수기 입력. 매니저 팝업(`T_SHOP_SMAS`), 실사예정일 셀 더블클릭으로 날짜 지정(비우면 미정), 2단 헤더 엑셀 |
| 관리자 (ADMIN만 표시) | 사용자별 권한(ADMIN/USER), 페이지 권한, AI 사용 여부, 일일 한도, 계정 사용 중지 관리. 전역 AI 설정(기본 한도, 모델, effort), AI 사용 현황, 로그인 기록·잠금 해제, 접속 세션 강제 로그아웃 |

### 권한과 한도
- `250016`(`SUPER_ADMIN_ID`)은 항상 ADMIN이며, 권한을 바꾸거나 비활성화할 수 없습니다. 나머지 사용자는 처음 로그인할 때 일반(USER) 권한으로 자동 등록됩니다.
- AI 기본 한도는 사용자당 하루 **질문 10회, 비용 $2.00**입니다. 관리자 화면에서 기본값을 바꾸거나 사용자별로 따로 지정할 수 있습니다.
- 비용은 응답 토큰 사용량(입력·출력·캐시)에 모델 단가를 곱해 계산합니다. 답변 도중 한도에 도달하면 그 자리에서 중단합니다.
- 서버 오류로 답변을 전혀 받지 못한 질문은 질문 수에서 빼 줍니다.
- 페이지 권한은 서버 API에서도 검사하므로, 화면에서 메뉴만 숨기는 방식이 아닙니다.

## 실행 (로컬 배포)
1. `.env.example`을 복사해 `.env`를 만들고 DB 정보와 `ANTHROPIC_API_KEY`를 입력합니다.
2. 처음 한 번만 `setup.bat`를 실행합니다. Python 가상환경을 만들고 패키지를 설치한 뒤 프론트엔드를 빌드합니다.
3. `start.bat`를 실행하면 http://localhost:8000 에서 API와 화면이 함께 서비스됩니다.

개발 중에는 `dev.bat`를 실행합니다. 백엔드는 8000번(자동 재시작), 프론트는 5173번(HMR)에서 뜹니다.

서비스 자체 데이터(권한, 세션, 사용량, 대화 기록, 즐겨찾기)는 `backend/data/app.db`(SQLite)에 저장됩니다. 이 파일은 git에 올라가지 않습니다.

```
backend/app/
  config.py        .env 로드
  db.py            Oracle Thick 모드 커넥션 풀
  store.py         SQLite 저장소 (권한/세션/사용량/대화/즐겨찾기/개인설정)
  auth.py          로그인·잠금·슬라이딩 세션·페이지 권한 검사
  usage.py         모델 단가, 비용 계산, 일일 한도
  admin.py         관리자 기능
  data_service.py  대시보드 집계, 일자별 조회·필터·정렬, 엑셀 생성
  chat_tools.py    Claude용 조회 도구 (화이트리스트 기반 파라미터 쿼리)
  chat_service.py  Claude 스트리밍, 도구 호출 루프, 대화 저장, 일시 오류 재시도
  main.py          FastAPI 라우트
frontend/src/
  App.tsx                     로그인 게이트, 세션 타이머, URL 공유, 권한별 메뉴
  components/LoginView.tsx    로그인
  components/DashboardView.tsx, DetailView.tsx
  components/ChatWidget.tsx   대화, 기록, 즐겨찾기, 차트
  components/AdminView.tsx    관리자
```
